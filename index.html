Questions fréquentes

Ce que vous souhaitez savoir

Faut-il déjà maîtriser l’informatique pour s’inscrire ?

Pas nécessairement. Certaines formations sont conçues pour les débutants. Contactez-nous afin de vérifier le niveau conseillé pour votre parcours.

Comment connaître les tarifs et les prochaines sessions ?

Envoyez une demande via le formulaire. Les tarifs, calendriers et modalités seront confirmés par l’équipe du centre.

Comment valider mon inscription ?

Une demande sur ce site constitue une prise de contact et non une inscription définitive. Attendez la confirmation du centre pour valider les modalités.

Les formations sont-elles toutes disponibles immédiatement ?

Le catalogue présente les domaines de formation. Les sessions réellement ouvertes doivent être confirmées auprès de l’équipe SIB.
